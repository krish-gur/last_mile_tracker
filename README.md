# 📦 Last-Mile Delivery Tracker

A full-featured delivery management platform and REST API built to handle dynamic rate calculation, automated delivery agent allocation, real-time status transitions, and immutable audit logs.

## 🛠️ Tech Stack

- **Backend Framework:** FastAPI (Python 3)
- **Database & ORM:** SQLite / SQLAlchemy
- **Data Validation & Schemas:** Pydantic v2
- **Frontend Dashboard:** Vanilla JavaScript & HTML5
- **Notification Engine:** Event-driven logging dispatcher (simulating SMS/Email dispatch)
- **Cloud Hosting:** Render (Singapore Region)
