# Last-Mile Delivery Tracker

A comprehensive delivery management backend and interface featuring dynamic rate calculation, automated delivery agent assignment, and immutable status audit trails.

---

## 🛠️ Tech Stack
- **Backend API**: Python / FastAPI
- **Database & ORM**: SQLite / SQLAlchemy
- **Frontend**: Lightweight Vanilla JS & HTML5 Dashboard
- **Notification Simulation**: Python logging dispatcher (Email & SMS)
